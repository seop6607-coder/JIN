# 워독스 데미지 랩 (시안)

WARDOGS의 무기·갑옷·헬멧·건축물 장비 데미지를 부위별로 계산해 보여주는 비공식 팬 사이트 시안입니다.
디자인은 apple.com/kr의 레이아웃(글로벌 내비, 고정 로컬 내비, 풀블리드 히어로, 2열 프로모 타일, 구성 선택기, 모델 비교표)을 참고했습니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 됩니다.

```
wardogs-damage/
├── index.html      페이지 구조
├── css/style.css   디자인 토큰(라이트/다크)과 컴포넌트 스타일
├── js/data.js      무기·방어구·부위·탄종·폭발물·건축물·차량 수치
└── js/app.js       계산 로직과 화면 렌더링
```

## 화면 구성

| 섹션 | 내용 |
| --- | --- |
| 히어로 | M4 헤드샷 피해가 헬멧 등급(없음→L4)에 따라 65.8 → 23.0으로 줄어드는 계기판 |
| 계산기 | 무기·탄종·갑옷·헬멧 선택 → 12개 부위 인체 도식에 처치 탄수 색상 표시, 부위별 표 |
| 데미지 표 | 전체 무기 × 헬멧 5단계(머리) × 갑옷 5단계(가슴) 매트릭스. 처치 탄수/1발 피해/처치 시간 전환 |
| 방어구 비교 | 갑옷·헬멧 L1–L4를 애플 모델 비교 형식으로 나열 |
| 무기 라인업 | 검색·분류 필터, 카드 클릭 시 계산기에 적용 |
| 건축물 장비 | L81 박격포, Talon 9K-SAM, Vanguard CIWS, 폭발 거리 시뮬레이터, 건축물 파괴 기준 |
| 폭발물 / 차량 | C4, RPG-7, 클레이모어, 대전차 지뢰, IED / L2A6, SPH2, Havoc, M113 |

## 계산식

```
보호 부위   = 기본 피해 × 부위 배율 × 탄종 보정(방어구) × (1 − 방어구 감소율)
비보호 부위 = 기본 피해 × 부위 배율 × 탄종 보정(맨몸)
처치 탄수   = ceil(100 ÷ 1발 피해)
처치 시간   = (처치 탄수 − 1) × 60 ÷ RPM
```

## 데이터 주의

- 수치는 2026년 시즌 1 기준 커뮤니티 측정치이며, 자료마다 값이 다른 경우 여러 자료가 함께 가리키는 값을 택했습니다.
- `null`은 아직 측정 값을 확보하지 못한 항목으로, 화면에 "측정 대기"로 나옵니다 (일부 돌격소총, 산탄총, 발사기, 차량 무기 등).
- `est: true`는 같은 탄을 쓰는 무기에서 빌려 온 추정값입니다.
- 거리 감쇠와 방어구 내구도 소모는 아직 반영하지 않았습니다.
- 수치를 고치려면 `js/data.js`만 수정하면 됩니다.
