## 프레임 30초 필름 (`FRAME_Film.jsx`)

기획서 '프레임(FRAME) 30초 제품 필름 기획서'의 30초 콘티를 그대로 타임라인에 옮깁니다. 결과는 새 시퀀스 `프레임 FRAME - 30초 필름`입니다.

**1. 촬영본에 장면 이름 붙이기** (셋 중 편한 방법 하나)

| 방법 | 예 |
|---|---|
| 클립 이름에 장면 이름 | `정면 화면_take2.mov`, `C7010_각도기.MP4`, `xbox.mp4` |
| 클립 이름 앞에 장면 번호 | `03_front.mov`, `S06 tilt.mp4`, `#12.mov` |
| 장면 이름으로 만든 빈(폴더)에 넣기 | 빈 `사운드바 뒷면` 또는 `10 사운드바 뒷면` 안에 클립 |

띄어쓰기·밑줄·대소문자는 상관없고, 맥에서 가져온 한글 파일 이름도 알아봅니다. 여러 장면 이름이 들어 있으면 더 긴 이름이 이깁니다 (`정면_플스기둥` → 플스 기둥, `사운드바_뒷면` → 사운드바 뒷면).

| # | 장면 | 길이 | 알아보는 이름 |
|---|---|---|---|
| 1 | 뒷면 하단 | 1.5초 | 뒷면하단, 후면하단, 하판, rear bottom, base |
| 2 | 기둥 | 3초 | 기둥, pole, column |
| 3 | 정면 화면 | 3초 | 정면 화면, 정면, front |

| 6 | 각도기 움직임 | 3초 | 각도기, 각도, tilt, angle |
| 7 | 가림판 부착 | 1.5초 | 가림판, cover |

| 15 | 엔딩 히어로 | 4.5초 | 엔딩, ending (없으면 정면 화면 클립의 다른 구간) |

**2. 쓸 구간 고르기** (안 해도 됩니다)
- 클립을 **시퀀스 01**에 놓아 두면 그 In 지점부터 쓰고, 시퀀스 01에서 맞춘 크기·위치도 그대로 가져옵니다.
- 소스 모니터에서 **In 마크**를 찍어 두면 그 지점부터 씁니다. 각도기 컷은 움직임이 시작되기 0.75초 전에 In을 찍으세요 (정지 0.75초 → 움직임 1.5초 → 정지 0.75초).
- 둘 다 없으면 클립 가운데를 씁니다. 한 장면에 클립이 여러 개면 시퀀스 01에 놓인 것 → In 마크가 있는 것 → 긴 것 순으로 고릅니다.

**3. 음악**: `The Light`를 프로젝트로 가져오기만 하면 됩니다. 2:07.53부터 22.5초 + 2:54.03부터 7.5초를 이어 붙여 정확히 30초가 되고, 드롭이 정면 화면 컷(4.5초)에 맞습니다. 이어 붙인 자리는 12번 → 13번 컷에 숨고, 앞 0.25초 페이드 인 / 끝 1.5초 페이드 아웃이 들어갑니다. 이름에 `FRAME_music_edit`가 들어간 30초 편집본이 프로젝트에 있으면 그 파일을 그대로 깝니다. 음악이 한두 프레임 어긋나 들리면 `MUSIC_NUDGE_FRAMES`로 보정합니다.

**4. 결과**
- 15컷이 킥 그리드(24fps 기준 18프레임 배수)에 딱 맞게 놓입니다. 첫 컷은 0.25초 페이드 인, 엔딩은 마지막 1.5초 페이드 투 블랙.
- 컷 안 움직임은 레퍼런스 스타일 그대로입니다. 히어로는 거의 멈춘 느린 푸시, 디테일은 1.5초 동안 분명한 슬라이드·틸트·롤. 매치컷 12~14번(플스 기둥 → 닌텐도 → 엑스박스)은 셋이 똑같이 움직입니다. 9~10번(사운드바 앞 → 뒤)은 같은 방향으로 밀립니다.
- 촬영본이 없는 장면은 회색 **자리표시 카드**(장면 번호 + 이름)로 채워서 박자가 어긋나지 않습니다. 촬영 후 다시 실행하면 새 시퀀스가 하나 더 생깁니다.
- 타임라인에 장면 이름 마커(`03 정면 화면` 등)가 붙고, 드롭·음악 이음새·쓴 클립 이름이 마커 설명에 남습니다. 영상 안에는 글자가 들어가지 않습니다.
- 가로 시퀀스에서는 세로 촬영본을 쓰지 않습니다. 원본 시퀀스를 **세로(9:16)**로 만들어 두고 실행하면 세로 촬영본만 골라 세로 버전을 만듭니다.
- 어떤 클립의 몇 초~몇 초를 썼는지는 프로젝트 폴더의 `FRAME_Film_log.txt` 컷 리스트에 남습니다.

**설정** (`FRAME_Film.jsx` 위쪽 `CONFIG`)

| 설정 | 기본값 | 설명 |
|---|---|---|
| `SOURCE_SEQUENCE_NAME` | `""` | 해상도·프레임 기준 시퀀스. 비우면 `시퀀스 01` / `Sequence 01` |
| `KICK_SEC` | `0.75` | 킥 간격 (The Light 80 BPM) |
| `MOTION_INTENSITY` | `1.0` | 컷 안 움직임 강도. `0`이면 움직임 없이 컷만 |
| `MUSIC_NAME` | `""` | 음악 파일 이름 일부. 비우면 `The Light` → 가장 긴 오디오 |
| `MUSIC_NUDGE_FRAMES` | `0` | 음악 싱크 보정 (+ = 음악을 늦게) |
| `MUSIC_FADE_IN_SEC` / `MUSIC_FADE_OUT_SEC` | `0.25` / `1.5` | 음악 페이드 |
| `ADD_SCENE_MARKERS` | `true` | 장면 이름 마커 |
| `USE_SLATES` | `true` | 빠진 장면을 자리표시 카드로 채움 (`false`면 비워 둠) |

시퀀스는 24fps(23.976)를 권장합니다. 30fps 등에서는 킥이 반 프레임 이내로 어긋날 수 있어 요약 창에 알려 줍니다.

**장면·길이 바꾸기 (개발자용)**: `film/frame_scenes.json` 수정 → (장면 이름을 바꿨다면) `python3 premiere/film/make_slates.py 폰트폴더` → `python3 premiere/film/build.py frame`. 원본 소스는 `film/frame_head.js`, `film/frame_main.js`이고 공통 엔진은 `PremiumEdit.jsx`의 `@@SHARED` 구간입니다.

## MELT 2세대 브랜드 필름 (`MELT2_BrandFilm.jsx`)

**구성 (약 30초, 1박자 = 1.13초 = 레퍼런스 컷 간격)**

```
오프닝 제품 샷 (어둠에서 밝아짐, 거의 정지)      3박자
[두 번째 진화]                                   2박자
디테일 2컷 (확대+회전 / 위로 훑기 ...)            1박자씩
[공간에 녹아드는 실루엣]                         1박자
디테일 3컷                                        1박자씩
[보이지 않는 곳의 완성]                          1박자
디테일 2컷 + 차분한 컷                            1박자씩
[흔들림 없는 자유]                               1박자
긴 제품 샷 (아주 느린 풀)                        4.5박자
엔딩 제품 샷 (오프닝과 같은 소스, 페이드 인/아웃) 1.5박자
MELT / 2nd Generation                             2.5박자
MOVLABS                                           2박자 (페이드 아웃)
```

**카피** (`film/copy.json`)

| 문구 | 의미 |
|---|---|
| 두 번째 진화 | 2세대 출시 (레퍼런스 '또 하나의 작품' 자리) |
| 공간에 녹아드는 실루엣 | MELT(녹아들다) + 실루엣 — 공간에 자연스럽게 스며드는 미니멀 디자인 |
| 보이지 않는 곳의 완성 | 일체형 후면 수납 — 선과 기기를 뒤에 숨겨 완성하는 정리 |
| 흔들림 없는 자유 | 이동식 바퀴의 자유로움 + 큰 TV도 흔들림 없는 안정감 |

**소스 고르는 방식**
- 시퀀스 01에서 이미 쓴 구간(검증된 좋은 컷)과 프로젝트의 다른 영상 소스를 번갈아 사용합니다. 순서와 컷은 새로 구성합니다.
- 제품 샷은 긴 구간에서, 디테일은 1박자 길이로 여러 소스에서 뽑고, 같은 소스가 연속되지 않게 합니다. 한 번 쓴 구간은 다시 쓰지 않습니다.
- 세로 영상 등 화면 비율이 크게 다른 소스, 사진, 시퀀스, 오디오는 영상 컷으로 쓰지 않습니다.
- 음악은 시퀀스 01에 쓰인 음악(없으면 프로젝트에서 가장 긴 음악 파일)을 같은 시작 지점부터 깔고 끝에서 2초 페이드아웃합니다.
- 흑백 + 대비 (Lumetri Color 채도 0, 대비 +25)를 영상 클립마다 넣습니다. 끄려면 `MONOCHROME: false`.
- 빈 블랙 비디오는 쓰지 않습니다. 문구 카드는 검은 배경 이미지입니다 (실행하면 프로젝트 폴더의 `MELT2_titles`에 저장되고 `MELT2 Titles` 빈으로 들어옵니다).
- 어떤 소스의 몇 초~몇 초를 썼는지는 프로젝트 폴더의 `MELT2_BrandFilm_log.txt` 컷 리스트에 남습니다.

**문구 바꾸기 (개발자용)**: `film/copy.json` 수정 → `python3 premiere/film/make_titles.py 폰트폴더` → `python3 premiere/film/build.py`. 원본 소스는 `film/film_head.js`, `film/film_main.js`이고, 공통 엔진은 `PremiumEdit.jsx`의 `@@SHARED` 구간을 그대로 가져옵니다.

# Premium Edit — 시퀀스 01 모션 편집 (`PremiumEdit.jsx`)

`PremiumEdit.jsx`는 **시퀀스 01**을 그대로 두고, 그 내용을 바탕으로 **새 시퀀스(`시퀀스 01 - Premium Edit`)** 를 만든 뒤 편집을 자동으로 적용합니다.

편집 스타일은 두 가지이고, 기본값은 **레퍼런스 스타일**(MOVLABS ART STAND 영상 분석 결과)입니다.

| 스타일 | 느낌 |
|---|---|
| `REFERENCE` (기본) | 전환은 딱 끊는 컷. 긴 제품 샷은 거의 멈춘 듯 아주 느리게 다가가고, 1초 남짓한 디테일 샷은 크게 움직임 (확대+회전, 위로 훑기, 옆으로 밀기, 회전 줌). 첫 클립은 어둠에서 밝아지며 시작하고 마지막 클립은 어둡게 끝남 |
| `SOFT` | 첫 버전. 디졸브 위주로 부드럽고 움직임이 작음 |

| 요청 | 적용 방식 |
|---|---|
| 영상 순서 배치는 똑같이 | 원본 클립을 시작 시간 순서 그대로 배치 (레퍼런스: V1 한 줄 / 소프트: V1·V2에 번갈아 놓는 A/B 롤) |
| 블랙 비디오 없게 | `블랙 비디오`/`Black Video`/`투명 비디오` 클립과 빈 구간(갭)을 모두 빼고 앞으로 당겨 붙임. 회전·이동 때문에 화면 가장자리에 검은 여백이 생기지 않도록 필요한 최소 스케일을 클립마다 계산해서 보정 |
| 스케일·오페시티·로테이션·포지션을 섞어서 | 스케일: 전 클립 (느린 푸시 인/풀 아웃 + 등장 세틀)<br>포지션: 좌우 팬, 위로 흐르는 무브<br>로테이션: 0.5~1.2° 정도의 아주 작은 롤 (일부 클립만)<br>오페시티: 교차 디졸브 / 줌 디졸브 |
| 지루하지 않되 정신 사납지 않게 | 컷 전환 방식을 규칙적으로 번갈아 사용 (디졸브 → 컷+세틀 → 줌 디졸브 → 컷+세틀 …). 모든 움직임은 이징(ease-out)으로 부드럽게 처리하고, 짧은 클립일수록 움직임 폭을 줄임 |

원본 **시퀀스 01은 전혀 수정하지 않습니다.** 결과가 마음에 들지 않으면 새로 생긴 시퀀스만 지우면 됩니다.

## 실행 방법 (처음 한 번만 준비하면 됩니다)

Premiere Pro에는 스크립트 실행 메뉴가 없어서, 무료 프로그램 **VS Code**와 Adobe 공식 확장 **ExtendScript Debugger**로 실행합니다.

1. **프로젝트 저장**: Premiere Pro에서 작업 중인 프로젝트를 열고 `Ctrl+S`로 저장합니다. 백업도 한 번 해 두면 안전합니다.
2. **VS Code 설치**: https://code.visualstudio.com
3. **확장 설치**: VS Code 왼쪽의 확장(Extensions) 아이콘에서 `ExtendScript Debugger`(게시자: Adobe)를 검색해 설치합니다.
4. **스크립트 열기**: VS Code에서 `파일 > 파일 열기`로 이 폴더의 `PremiumEdit.jsx`를 엽니다.
5. **실행**
   - `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`) → `ExtendScript: Evaluate Script in Attached Host` 실행
   - 대상 앱 목록이 나오면 **Adobe Premiere Pro**를 선택합니다.
6. 클립 개수에 따라 수십 초에서 몇 분 정도 걸립니다. 끝나면 Premiere에 결과 요약 창이 뜨고 새 시퀀스가 타임라인에 열립니다.
   상세 로그는 프로젝트 파일과 같은 폴더의 `PremiumEdit_log.txt`에 저장됩니다.

> ExtendScript(.jsx)를 지원하는 Premiere Pro 버전이 필요합니다 (2020 이후 대부분의 버전). 대상 앱 목록에 Premiere Pro가 보이지 않으면 Premiere Pro를 먼저 실행한 뒤 다시 시도하세요.

```
V2 이상 : 원본의 오버레이(로고 PNG, 자막 이미지, 조정 레이어 등) - 원본 위치/모션 그대로
V1      : 모든 영상 클립 (원본 순서)
A1~     : 원본에 있던 클립 오디오, 그 다음 트랙부터 음악·내레이션 (영상 길이에 맞게 자르고 끝 2초 페이드아웃)

[소프트 스타일]
V3 이상 : 오버레이
V2 / V1 : 짝수 / 홀수 번째 클립 (디졸브 시 위에서 페이드 인/아웃)
A1/A2   : 클립 오디오 (디졸브 구간은 오디오 크로스페이드), A3 이상: 음악 등
```

### 레퍼런스 스타일 (기본)

레퍼런스 영상에서 샷마다 확대·이동·회전 양을 측정해서 만든 값입니다.

| 레퍼런스에서 측정한 것 | 스크립트 적용 |
|---|---|
| 제품 전체 샷: 3.4초 동안 +2.2% 확대, 거의 정지 | `HERO_PUSH` / `HERO_PULL`: 3초에 3% 정도 아주 느린 푸시·풀 (2.4초 이상 클립, 첫·마지막 클립) |
| 디테일 샷: 1.1초 동안 +20% 확대 + 4.7° 회전 | `PUSH_ROLL`: +4% → +20% 확대하며 4.5° 회전 |
| 디테일 샷: 화면 높이 18%를 위로 훑고 끝에서 멈춤 | `TILT_REVEAL`: 9% 아래에서 올라와 부드럽게 멈춤 |
| 디테일 샷: 크게 돌면서 확대 | `SPIN_ZOOM`: +12% → +45% 확대하며 10° 회전 |
| 로고 샷: 대각선으로 흐르며 살짝 멀어짐 | `DRIFT_PULL`, `SLIDE` |
| 전환: 디졸브 없이 전부 컷, 시작은 페이드 인 | 전부 컷, 시작 0.8초 페이드 인 / 끝 0.6초 페이드 아웃 |

같은 움직임이 다시 나오면 방향(좌/우, 회전 방향)을 뒤집어서 반복감을 줄입니다. 원본 해상도보다 1.35배 넘게 키워야 하면 화질이 흐려지지 않게 움직임을 자동으로 줄입니다 (4K 소스는 크게, 1080p 소스는 조금 작게 움직임).

### 소프트 스타일

| 구분 | 이름 | 움직임 |
|---|---|---|
| 클립 기본 무브 | `PUSH_IN` | 1.5% → 7.5% 천천히 다가감 |
| | `PULL_OUT` | 8.5% → 2% 천천히 멀어짐 |
| | `PAN_LEFT` / `PAN_RIGHT` | 화면 폭 ±1.4% 좌우로 흐름 |
| | `RISE` | 위로 살짝 흐름 |
| | `ROLL_PUSH` | -0.7° → +0.5° 회전하며 푸시 |
| 첫 클립 | 오프닝 | 10% 확대 상태에서 1.8초 동안 부드럽게 안착 |
| 전환 | `DISSOLVE` | 0.6초 교차 디졸브 + 들어오는 클립 3.5% 세틀 |
| | `ZOOM_DISSOLVE` | 나가는 클립 7% 줌 인 + 0.8° 롤 → 0.4초 디졸브 → 들어오는 클립 9% 확대 상태에서 안착 |
| | `CUT_SETTLE` | 하드 컷 + 들어오는 클립 7% 확대 상태에서 0.6초 착지 (두 번에 한 번 1.2° 롤) |

디졸브는 클립 앞뒤 여분(핸들)을 사용해서 **원래 컷 타이밍을 유지**합니다. 여분이 없는 클립은 자동으로 컷+세틀로 바뀝니다.

## 설정 바꾸기

`PremiumEdit.jsx` 위쪽의 `CONFIG`에서 값만 바꾸고 다시 실행하면 새 시퀀스가 하나 더 생깁니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `SOURCE_SEQUENCE_NAME` | `""` | 원본 시퀀스 이름. 비워두면 `시퀀스 01` / `Sequence 01`을 자동으로 찾음 |
| `STYLE` | `"REFERENCE"` | 편집 스타일. 첫 버전(디졸브 위주)은 `"SOFT"` |
| `HERO_MIN_SEC` | `2.4` | 이 길이 이상은 '제품 전체 샷'(느린 움직임), 짧으면 '디테일 샷'(큰 움직임) |
| `DETAIL_PATTERN` | 8개 반복 | 디테일 샷 움직임 순서 |
| `OPEN_FADE_SEC` / `END_FADE_SEC` | `0.8` / `0.6` | 시작 페이드 인 / 끝 페이드 아웃. **검은 화면이 전혀 없게 하려면 둘 다 `0`** |
| `MAX_UPSCALE` | `1.35` | 원본 해상도 대비 최대 확대 배율 (화질 보호) |
| `MOTION_INTENSITY` | `1.0` | 전체 모션 강도. 더 차분하게 `0.6`, 더 역동적으로 `1.3` |
| `DISSOLVE_SEC` | `0.6` | [SOFT] 디졸브 길이(초) |
| `TRANSITION_PATTERN` | 디졸브/컷+세틀/줌 디졸브 반복 | [SOFT] 전환 순서 |
| `MOTION_PATTERN` | 8개 무브 반복 | [SOFT] 클립별 카메라 무브 순서 |
| `FILL_FRAME_MAX_ZOOM` | `1.35` | 화면 비율이 다른 클립을 꽉 채우기 위해 허용하는 최대 확대. **세로 영상도 양옆 검은 여백 없이 꽉 채우려면 `4`로** (위아래가 잘립니다) |
| `MUSIC_FADE_OUT_SEC` | `2.0` | 음악 끝 페이드아웃 길이 |
| `KEYFRAME_TIME_BASE` | `"media"` | 키프레임이 클립마다 일정하게 밀려 보이면 `"clip"`으로 바꿔서 다시 실행 |

## 알아둘 점

- **이펙트(루메트리 색보정 등)는 복사되지 않습니다.** 원본 클립을 선택해 `Ctrl+C` → 새 시퀀스의 클립을 선택하고 `Ctrl+Alt+V`(특성 붙여넣기)에서 **모션·불투명도는 체크 해제**하고 붙여넣으세요. 조정 레이어는 자리만 복사되니 같은 방법으로 이펙트를 옮기면 됩니다.
- **속도를 바꾼 클립**은 100% 속도로 배치됩니다 (길이는 원본과 같게). 필요하면 새 시퀀스에서 다시 속도를 적용하세요.
- **텍스트/그래픽 클립**(에센셜 그래픽)은 프로젝트 패널에 원본 파일이 없어서 자동으로 복사되지 않습니다. 원본 시퀀스에서 복사해 V3 이상에 붙여넣으세요.
- **세로 영상처럼 화면 비율이 크게 다른 클립**은 인물이 잘리지 않도록 원본 프레이밍(양옆 여백)을 유지하고 스케일 모션만 줍니다. 꽉 채우려면 `FILL_FRAME_MAX_ZOOM`을 `4`로 바꾸세요.
- 영상 파일에서 분리해 따로 쓴 오디오는 영상이 딸려 들어가 스토리 클립을 덮어쓸 위험이 있어 옮기지 않고, 요약 창에 위치를 알려 줍니다.
- 원본 시퀀스의 마커는 새 타이밍에 맞게 옮겨 둡니다 (Premiere 버전에 따라 원래 위치에 남을 수 있음).

## 개발자용: 테스트

Premiere 없이 Node.js로 스크립트 전체 흐름을 검증하는 모의(mock) 환경이 `test/`에 있습니다.

```bash
node premiere/test/run_test.js                 # 기본 (1080p, 30fps)
node premiere/test/run_test.js --ko --fps=24   # 한글 UI 이름, 24fps
node premiere/test/run_test.js --tcOffset --inclusiveOut --noUnlink --strayKey --longStill --fps=60
node premiere/test/run_test.js --oneTrack --noQE
node premiere/test/run_test.js --soft          # 소프트 스타일
node premiere/test/run_test.js --refScenario --fps=23.976   # 레퍼런스 영상과 같은 샷 리듬
```

검사 항목: 원본 시퀀스 불변, 클립 순서 동일, 블랙 비디오 없음, **모든 프레임이 불투명한 클립으로 화면 전체를 덮는지(검은 여백 0프레임)**, 원본과 같은 소스 구간 사용, 오버레이·음악 처리, In/Out 마크 원상 복구.

브랜드 필름 스크립트 테스트 (사용자 프로젝트와 비슷한 가상 프로젝트: 4K 카메라 소스, 8초 AI 소스, 세로 영상, 음악, 로고):
